# ADR-006. Зберігання нормалізованих записів замість сирого GTFS

Статус: прийнято, 2026-10-11

## Контекст

GTFS-фіди містять набір CSV-файлів зі структурою, визначеною стандартом GTFS. Під час імпорту необхідно вирішити, чи зберігати оригінальні записи джерела, чи лише нормалізовані доменні сутності.

## Розглянуті варіанти

### 1) Зберігати сирі записи GTFS

Переваги:
- можна повністю відтворити імпорт;
- зручно для аудиту та налагодження.

Недоліки:
- дублювання даних;
- збільшення обсягу бази;
- додаткова складність схеми.

### 2) Зберігати лише нормалізовані сутності

Переваги:
- простіша схема БД;
- менший обсяг збережених даних;
- усі дані готові до використання бізнес-логікою.

Недоліки:
- неможливо відновити початковий CSV-запис;
- складніше аналізувати помилки джерела після імпорту.

## Рішення

Після імпорту зберігати лише нормалізовані доменні сутності.

## Наслідки

### Позитивні

- простіша модель даних;
- швидший доступ до інформації;
- менші вимоги до сховища.

### Негативні

- втрачається оригінальне представлення запису;
- аудит імпорту ускладнюється.

## Умова перегляду

Рішення переглядається, якщо виникне вимога повного аудиту або повторного відтворення процесу імпорту.
